# 如何高效做学习笔记：我的方法论

记了很多笔记，回头却从不看；记笔记变成「抄书」，抄完就忘了。这是大多数人的困惑。这篇分享我的笔记方法论，核心一句话：**笔记是给未来的自己看的，不是给现在的手抄的。**

## 一、选对工具：轻量、可检索、可版本化

工具不重要，但也不能太折腾。我的推荐标准是：

- **纯文本优先**（Markdown），十年后还能打开
- **全局可搜索**，找得到才算记过
- **支持版本管理**，改坏了能回滚

于是我的方案就很简单：本地文件夹 + 一个 Markdown 编辑器 + Git 备份。

## 二、记什么：三类内容，三种记法

不是所有东西都值得记，我把笔记分成三类：

| 类型 | 典型内容 | 记法 |
| ---- | -------- | ---- |
| 知识型 | 概念、原理、API | 用自己的话改写，附示例 |
| 过程型 | 排错记录、踩坑 | 问题 → 排查 → 结论 |
| 思考型 | 想法、复盘、灵感 | 只记观点和论据 |

```markdown
<!-- 一张过程型笔记的模板 -->
## 问题描述
一句话说清楚现象

## 排查过程
1. 第一步尝试了什么
2. 观察到了什么现象

## 结论
根因是什么？下次如何避免？
```

## 三、怎么用：定期回顾 > 反复重记

笔记的价值在「用」而不在「记」。我给自己定了三条回顾规则：

1. **每周五**：翻一遍本周笔记，合并重复项
2. **每月底**：挑一篇写成文章 / 讲给别人听
3. **检索优先**：任何时候先搜，搜不到再补记

> 费曼学习法的精髓：如果你不能把学到的内容讲给一个外行听懂，那你还没有真正掌握它。笔记回顾，就是最简单的「讲给自己听」。

## 最后

把笔记当成自己**第二大脑**的输入端。坚持半年，你会发现知识不再是散落的碎片，而是能互相连成网、随时调用的资产。
