# 我的技术学习路线：从入门到进阶

技术学习最怕的不是没有资料，而是**不知道先学什么、按什么顺序学**。这篇路线图整理了我自己摸索出的路径，按「打基础 → 做项目 → 深进阶」三个阶段展开，希望对你有所启发。

## 一、打基础：选对一门语言，深入它

很多人纠结「先学 A 还是先学 B」，其实对于初学者来说，**选择本身没有对错，坚持才是关键**。建议锁定一门主语言，啃透它的语法、常用库和最佳实践。

以 JavaScript 为例，基础阶段应该覆盖：

- 变量、数据类型、运算符
- 函数、作用域、闭包
- 数组与对象常用方法
- 异步编程（Promise / async-await）

> 别急着「学完所有细节」再动手。用 30% 的时间掌握核心，剩下 70% 的时间直接开项目，缺什么补什么，效率最高。

## 二、做项目：用项目驱动学习

理论知识如果不用，两周就会忘光。项目是最好的「记忆增强器」。初级可以从 200 行以内的小工具开始：

1. 一个命令行待办清单
2. 一个网页版计算器
3. 一个抓取并展示数据的爬虫 / 小脚本

### 项目完成标准

| 阶段 | 目标 | 自查清单 |
| ---- | ---- | -------- |
| 跑通 | 功能可用 | 输入输出符合预期？ |
| 重构 | 结构清晰 | 重复代码是否抽成函数？ |
| 上线 | 别人能用 | 有没有写文档和部署？ |

## 三、深进阶：建立体系化认知

做完三五个项目后，就该从「会写」走向「懂原理」了。这时重点转向：

- 读官方文档与源码
- 学习设计模式与架构思想
- 研究性能、安全、测试等工程话题

```bash
# 一个粗糙的「学习闭环」脚本示意
while not_fluent(subject):
    read(subject)
    write_code(subject)
    explain_to_others(subject)
```

最后想说的是：**路线图只是地图，路还是要自己走。** 不必追求一步到位，保持每周都有产出，一年后的你会感谢现在的坚持。
